# Assumptions, risks, and open questions

## Ranked differentiators

1. **Visible provenance and confidence:** especially persuasive because every central fact is public and imperfect.
2. **Network uniqueness plus self-overlap:** demonstrates geography changes decisions beyond pin placement.
3. **Peer-aware, non-financial health proxy:** avoids comparing airport/mall/community formats as though identical.
4. **Competition as validation and saturation:** avoids the naïve “few salons means grow” story.
5. **Scenario deltas with grounded analyst:** demonstrates practical AI without outsourcing scores to an LLM.

## Material risks

| Risk | Mitigation |
|---|---|
| Branch roster/coordinates conflict or stale | Reconciliation log, field-level confidence, snapshot date, manual validation queue |
| UAE POI coverage or licensing weak | Compare Overture/OSM/official sources; disclose geographic coverage; do not overclaim |
| Public proxies mistaken for performance | Persistent wording, source/evidence panel, no revenue labels |
| Subjective weights | Versioned config, rationale, sensitivity/scenarios, golden cases |
| Catchment false precision | Call radii radii; validate before any routing upgrade |
| AI hallucinates | Typed allowlist, evidence-only synthesis, evals, fallback |
| Reviewer setup friction | Committed snapshot, no-secret mode, tested README later |
